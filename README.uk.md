## Зламана система

Мобільний зв'язок - це картель з одного: одна SIM-картка, один оператор, один контракт, один закритий сад.
Карти покриття - це маркетингові брошури; сільські вулиці випадають із них; квартири втрачають сигнал;
а ви - людина, яка платить, - не володієте жодною з інфраструктур, які вас обслуговують. Якщо ваш національний
оператор підвищить ціну або його вежа замовкне, вашим єдиним вибором буде… інша монополія з тими самими
вежами та тими самими умовами.

Модем у вашій кишені може говорити з базовою станцією за 20 метрів. Єдина причина, чому він не говорить
із *вашою* базовою станцією, полягає в тому, що цій станції ніколи не дозволяли бути вашою.

## Рішення HyperonX

**Fairwave - це громадський оператор: повноцінна відкрита мала сота, яка вміщується в коробку
з-під піци та підключається до звичайного Ethernet.**

Кафе, житловий кооператив, сільський зал, район - будь-хто може запустити одну:

1. Завантажте образ Fairwave на міні-ПК (x86 або ARM) із підключеним SDR.
2. Виконайте `fairwave node init`, відповідайте на регуляторний чек-лист (передача вимкнена, доки ви не доведете авторизацію).
3. Випускайте SIM-картки Fairwave для своєї громади - картки, якими володієте ви, облікові дані, які контролюєте ви.
4. Телефони підключаються. Трафік залишається локальним, коли це можливо; кілька коробок об'єднуються в сітку;
   вихід в інтернет іде захищеним тунелем WireGuard, коли ви цього хочете.

Побудовано на перевіреній відкритій інфраструктурі - **Open5GS** (EPC) та **srsRAN** (eNB/gNB) - з панеллю
керування на Go, операторським дашбордом, офлайн-випуском SIM та лабораторним режимом, який запускає
весь оператор у Docker із нульовим радіовипромінюванням.

## Що ви отримуєте

- **Коробка з-під піци, яка є оператором**: ідентичність вузла, реєстрація, життєвий цикл
  (`provision → register → on-air → peer → breakout`) під керуванням `fairwave-control`.
- **Реальне підключення LTE**: Open5GS EPC + srsRAN eNB, налаштовуваний PLMN, зони відстеження,
  APN `internet` + `ims`, локальний вихід на межі.
- **Операції з SIM Fairwave**: офлайн-провізор; генерує Ki/OPc, пакети CSV/JSON для
  бюро карток, записує в HSS/UDM, контролює відкликання та заміну. Лабораторія та виробництво суворо розділені.
- **Лабораторна eSIM (SM-DP+)**: власний сервер профілів у стилі SGP.22 та програмна eUICC -
  зашифровані пакети прив'язаних профілів, QR-коди активації (`LPA:1$...`), повний цикл завантаження,
  перевірений у CI без обладнання. Лише лабораторія за задумом; відповідність GSMA відстежується як відкриті пункти.
- **Сусідська сітка**: виявлення mDNS, керування mTLS, площина даних WireGuard, обмін маршрутами.
- **Портал оператора**: локальний дашборд - UEs (із збереженням конфіденційності), транзит, піри, лабораторний режим.
- **Повний лабораторний режим**: уся мережа на чистому IP (zmq) із srsUE - без радіо, без ліцензії, дружній до CI.
- **Регуляторні ворота в коді**: увімкнення передачі вимагає код країни, підтвердження ліцензії
  та білий список частот. Інакше - вбудована відмова.

## Чому це загрожує чинним операторам

Захоплення оператора стає *необов'язковим для локального покриття*. Коли кафе, кооператив і село можуть
кожен запустити свою соту та об'єднати їх у сітку, національна SIM - це просто опція роумінгу, а не привратник.
Розвантаження, нейтральний доступ і тарифи за громадськими цінами перестають бути теорією. Fairwave не
копіює телеком-картель - він робить локальну монополію картелю оскаржуваною.

## Чому це можливо зараз

- **Open5GS** та **srsRAN** зрілі, близькі до виробництва та активно розвиваються.
- **SDR** (USRP, LimeSDR, BladeRF) покривають діапазони LTE з потужністю малої соти за сотні доларів.
- **Спільний спектр реальний**: CBRS у США, локальні ліцензії у Великій Британії/ЄС, приватні діапазони LTE.
- **Приватне LTE + дзвінки через Wi-Fi** дають законні шаблони замість удавання, що регулювання не існує.
- Обладнання класу міні-ПК (і Raspberry Pi CM4/5 + HAT для розробки) дешеве та достатнє.

## Швидкий старт - перше підключення UE за <30 хвилин (без радіо, без ліцензії)

> Вимоги: Docker Engine 24+, 8 ГБ ОЗП. Усе працює в контейнерах; нічого не передає.
> Для повного шляху даних (IP UE + ping) використовуйте нативний Linux; Docker Desktop на
> Windows/macOS проходить усі перевірки підключення на стороні EPC (див. [docs](docs/tutorials/lab-attach.md)).

```bash
./scripts/bootstrap.sh      # перевіряє/встановлює інструменти (Go, Docker, pre-commit)
make lab-up                 # збирає образи, піднімає EPC + eNB + srsUE, виконує перевірки підключення
make status                 # здоров'я одним поглядом: mme, sgwu/upf, enb, ue1
```

`make lab-up` перевіряє (і друкує) усе наступне:

1. Open5GS MME + HSS запущені
2. eNB S1-MME підключений до MME
3. RRC-з'єднання UE + випадковий доступ у лабораторному PLMN
4. NAS-аутентифікація UE + режим безпеки (milenage проти HSS)
5. MME створює стандартний EPS-носій і надсилає Attach Accept (IP UE виділено)

Потім зазирніть усередину:

```bash
fairwave node status                     # представлення панелі керування цього кластера
fairwave sim issue --count 2 --profile lab  # випустити дві лабораторні SIM
fairwave spectrum check --country US --band n48 --indoor  # демо спектральних воріт
make lab-down                            # зупинити все
```

(На Linux-хостах зі стабільним таймінгом ZMQ `docker exec -it ue1 ping -c3 10.45.0.1`
перевіряє повний шлях даних через тунель `tun_srsue`.)

Усе вищезазначене **безшумне в радіоефірі**: радіо емулюється віртуальними пристроями `srsran/zmq`.
Для реального обладнання дотримуйтесь [docs/tutorials/cafe-pilot.md](docs/tutorials/cafe-pilot.md) -
яке не дозволить увімкнути TX без виконання юридичного чек-листа.

## Статус

**Лабораторний реліз `v0.1.0`**: підключення EPC + zmq RAN + srsUE працює наскрізно; панель керування,
CLI, провізор SIM, лабораторна eSIM (SM-DP+) і сайт документації функціональні. Разом із ним опційно постачається ядро 5G SA на free5GC з обліком трафіку на основі CDR CHF (`core: free5gc`), з лабораторними профілями gNB/UE на ZMQ і CI-тестом підключення. Реальні радіочастотні
шляхи перевірені на обладнанні для розробки, але **вимкнені за замовчуванням**. Див. [дорожню карту](design/roadmap.md).

## Чим Fairwave НЕ є

- **Не перехоплювач IMSI** - жодного пасивного опитування; UE мають автентифікуватися даними, які випустили ви.
- **Не спектральний Дикий Захід** - передача захищена воротами, і ми відмовляємося від функцій обходу регулювання.
- **Не безкоштовний національний оператор** - це локальне покриття з необов'язковим виходом.
- **Не заміна екстреним викликам** - плануйте поведінку 911/112 у кожному розгортанні ([docs/ops/incident-response.md](docs/ops/incident-response.md)).
