## Сломанная система

Мобильная связь - это картель из одного: одна SIM-карта, один оператор, один контракт, один закрытый сад.
Карты покрытия - это маркетинговые брошюры; сельские улицы выпадают из них; в квартирах пропадает сигнал;
а вы - человек, который платит, - не владеете ни одной из инфраструктур, которые вас обслуживают. Если ваш
национальный оператор поднимет цены или его вышка замолчит, ваш единственный выбор - это… другая монополия
с теми же вышками и теми же условиями.

Модем в вашем кармане может говорить с базовой станцией в 20 метрах. Единственная причина, по которой он
не говорит с *вашей* базовой станцией, в том, что этой станции никогда не позволяли быть вашей.

## Решение HyperonX

**Fairwave - это общественный оператор: полноценная открытая малая сота, которая помещается в коробку
из-под пиццы и подключается к обычному Ethernet.**

Кафе, жилищный кооператив, сельский зал, район - любой может запустить одну:

1. Загрузите образ Fairwave на мини-ПК (x86 или ARM) с подключенным SDR.
2. Выполните `fairwave node init`, ответьте на нормативный чек-лист (передача остается выключенной, пока вы не докажете авторизацию).
3. Выпускайте SIM-карты Fairwave для своего сообщества - карты, которыми владеете вы, учетные данные, которые контролируете вы.
4. Телефоны подключаются. Трафик остается локальным, когда это возможно; несколько коробок объединяются в сетку;
   выход в интернет идет по защищенному туннелю WireGuard, когда вы этого хотите.

Построено на проверенной открытой инфраструктуре - **Open5GS** (EPC) и **srsRAN** (eNB/gNB) - с панелью
управления на Go, операторским дашбордом, офлайн-выпуском SIM и лабораторным режимом, который запускает
весь оператор в Docker с нулевым радиоизлучением.

## Что вы получаете

- **Коробка из-под пиццы, которая является оператором**: идентичность узла, регистрация, жизненный цикл
  (`provision → register → on-air → peer → breakout`) под управлением `fairwave-control`.
- **Реальное подключение LTE**: Open5GS EPC + srsRAN eNB, настраиваемый PLMN, зоны отслеживания,
  APN `internet` + `ims`, локальный выход на границе.
- **Операции с SIM Fairwave**: офлайн-провизор; генерирует Ki/OPc, пакеты CSV/JSON для
  бюро карт, записывает в HSS/UDM, контролирует отзыв и замену. Лаборатория и производство строго разделены.
- **Лабораторная eSIM (SM-DP+)**: собственный сервер профилей в стиле SGP.22 и программная eUICC -
  зашифрованные пакеты привязанных профилей, QR-коды активации (`LPA:1$...`), полный цикл загрузки,
  проверенный в CI без железа. Только лаборатория по замыслу; соответствие GSMA отслеживается как открытые пункты.
- **Соседская сетка**: обнаружение mDNS, управление mTLS, плоскость данных WireGuard, обмен маршрутами.
- **Портал оператора**: локальный дашборд - UEs (с сохранением конфиденциальности), транзит, пиры, лабораторный режим.
- **Полный лабораторный режим**: вся сеть на чистом IP (zmq) с srsUE - без радио, без лицензии, дружелюбно к CI.
- **Нормативные ворота в коде**: включение передачи требует код страны, подтверждение лицензии
  и белый список частот. Иначе - встроенный отказ.

## Почему это угрожает действующим операторам

Захват оператора становится *необязательным для локального покрытия*. Когда кафе, кооператив и деревня
могут управлять каждый своей сотой и объединять их в сетку, национальная SIM - это просто опция роуминга,
а не привратник. Разгрузка, нейтральный доступ и тарифы по общественным ценам перестают быть теорией.
Fairwave не копирует телеком-картель - он делает локальную монополию картеля оспоримой.

## Почему это возможно сейчас

- **Open5GS** и **srsRAN** зрелы, близки к производству и активно развиваются.
- **SDR** (USRP, LimeSDR, BladeRF) покрывают диапазоны LTE с мощностью малой соты за сотни долларов.
- **Совместный спектр реален**: CBRS в США, локальные лицензии в Великобритании/ЕС, частные диапазоны LTE.
- **Частное LTE + звонки по Wi-Fi** дают законные шаблоны вместо притворства, что регулирования не существует.
- Оборудование класса мини-ПК (и Raspberry Pi CM4/5 + HAT для разработки) дешево и достаточно.

## Быстрый старт - первое подключение UE за <30 минут (без радио, без лицензии)

> Требования: Docker Engine 24+, 8 ГБ ОЗУ. Все работает в контейнерах; ничего не передает.
> Для полного пути данных (IP UE + ping) используйте нативный Linux; Docker Desktop на
> Windows/macOS проходит все проверки подключения на стороне EPC (см. [docs](docs/tutorials/lab-attach.md)).

```bash
./scripts/bootstrap.sh      # проверяет/устанавливает инструменты (Go, Docker, pre-commit)
make lab-up                 # собирает образы, поднимает EPC + eNB + srsUE, выполняет проверки подключения
make status                 # здоровье одним взглядом: mme, sgwu/upf, enb, ue1
```

`make lab-up` проверяет (и печатает) все следующее:

1. Open5GS MME + HSS запущены
2. eNB S1-MME подключен к MME
3. RRC-соединение UE + случайный доступ в лабораторном PLMN
4. NAS-аутентификация UE + режим безопасности (milenage против HSS)
5. MME создает стандартный EPS-бearer и отправляет Attach Accept (IP UE выделен)

Затем загляните внутрь:

```bash
fairwave node status                     # представление контрольной плоскости этого кластера
fairwave sim issue --count 2 --profile lab  # выпустить две лабораторные SIM
fairwave spectrum check --country US --band n48 --indoor  # демо спектральных ворот
make lab-down                            # остановить все
```

(На Linux-хостах со стабильным таймингом ZMQ `docker exec -it ue1 ping -c3 10.45.0.1`
проверяет полный путь данных через туннель `tun_srsue`.)

Все вышеперечисленное **бесшумно в радиоэфире**: радио эмулируется виртуальными устройствами `srsran/zmq`.
Для реального железа следуйте [docs/tutorials/cafe-pilot.md](docs/tutorials/cafe-pilot.md) -
которое не позволит включить передачу без выполнения юридического чек-листа.

## Статус

**Лабораторный релиз `v0.1.0`**: подключение EPC + zmq RAN + srsUE работает из конца в конец; панель управления,
CLI, провизор SIM, лабораторная eSIM (SM-DP+) и сайт документации функциональны. Вместе с ним поставляется ядро 5G SA на free5GC с учётом трафика на основе CDR CHF (опционально, `core: free5gc`), с лабораторными профилями gNB/UE на ZMQ и CI-тестом подключения. Реальные радиочастотные
пути проверены на оборудовании для разработки, но **отключены по умолчанию**. См. [дорожную карту](design/roadmap.md).

## Чем Fairwave НЕ является

- **Не IMSI-перехватчик** - никакого пассивного опроса; UE должны аутентифицироваться учетными данными, которые выпустили вы.
- **Не спектральный Дикий Запад** - передача защищена воротами, и мы отказываемся от функций обхода регулирования.
- **Не бесплатный национальный оператор** - это локальное покрытие с необязательным выходом.
- **Не замена экстренным вызовам** - планируйте поведение 911/112 в каждом развертывании ([docs/ops/incident-response.md](docs/ops/incident-response.md)).
