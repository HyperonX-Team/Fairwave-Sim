Community-owned small cells.
Spectrum-safe by design.

Fairwave is an open-source small-cell network you can run on a desk: Open5GS EPC, srsRAN radio, a Go control plane, lab eSIM provisioning, and a lab-first workflow where RF stays off unless every legal gate has passed.

Live API status Get started in the lab
Lab first

No RF until you say so

ZMQ virtual radio by default. Transmit is off until country, license acknowledgment and band allow-list all pass - enforced in code, not by policy.

Real 4G core

Open5GS EPC

MME, SGW, PGW, HSS, PCRF with a Mongo subscriber store. Lab PLMN 999-99, APNs internet + ims, ready for your test SIMs.

Lab eSIM

eSIM via your own SM-DP+

A Go SM-DP+ and software eUICC run the full SGP.22-shaped profile download: encrypted bound profile packages, QR activation codes, CI-verified end to end.

Mesh

Peer and share

WireGuard mesh with control-plane-managed keys. Local breakout by default; optional cloud rendezvous hub for distributed sites.

Operator tools

One dashboard, one CLI

REST API v1, single-file operator UI, offline-first SIM provisioner with HSM-gated production profiles, Prometheus metrics.

Hardware

Community builds

260 mm pizza-box enclosure, BOM tiers from ~$350 community builds to CBRS-ready radios, SDR notes for USRP, LimeSDR and BladeRF.

Transparency

Open governance

ADRs for every architectural decision, threat model, privacy design, and a spectrum compliance checklist in the repo.

Legal banner. Fairwave is not carrier equipment and is not certified for unlicensed operation. Transmitting on licensed spectrum without authorization is unlawful in most jurisdictions. The project ships with RF disabled by default; hardware transmit requires explicit country, license acknowledgment and band allow-list gates. Use only in compliance with local law. 3GPP, Open5GS, srsRAN and other marks belong to their owners; Fairwave is independent.
